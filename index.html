METHODOLOGY

How to read this dashboard

People in need (PIN) is the principal measure displayed here. The dashboard retrieves country-level intersectoral People in Need records directly from the HDX Humanitarian API (HAPI).

The dashboard uses national-level records (admin_level = 0) and the total intersectoral population in need (population_status = INN). Demographic subsets such as Adult and Adult - Female are excluded.

Where HAPI provides multiple reporting periods for a country, the dashboard selects the record with the most recent reference-period end date.

Reference period matters. A PIN number is not necessarily a count of people identified on the day you visit this website. The reference period shown on each country card tells you the period to which the humanitarian assessment applies.

The dashboard reports connection failure rather than silently presenting old numbers as live data.

Source records are linked through their resource_hdx_id where available.
