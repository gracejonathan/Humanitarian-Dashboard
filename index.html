METHODOLOGY

How to read this dashboard

People in Need

People in Need (PIN) is the principal humanitarian measure displayed here. The dashboard retrieves country-level intersectoral PIN records directly from the HDX Humanitarian API (HAPI).

The dashboard uses national-level records (admin_level = 0) and the total intersectoral population in need (population_status = INN). Demographic subsets such as Adult and Adult - Female are excluded.

Where HAPI provides multiple reporting periods for a country, the dashboard selects the record with the most recent reference-period end date.

Reference period

A PIN number is not necessarily a count of people identified on the day you visit this website. The reference period shown on each country card identifies the period to which the humanitarian assessment applies.

Christian population

Christian population percentage is a separate demographic indicator. It comes from the World Religion Database dataset stored in data/religion.json.

Christian population percentage should not be interpreted as a measure of the number of churches, Christian organizations, humanitarian workers, or operational Christian presence in a crisis.

Christian presence

Where available, the dashboard also displays the separately curated Christian-presence assessment from data/crises.json. “Unknown” means that sufficient evidence has not yet been established; it does not mean absence.

Crisis chronology

Crisis type and start date are maintained separately from the live PIN data. They provide context for the humanitarian assessment but are not used to calculate the PIN figure.

Live-data principle

Humanitarian APIs can change their schemas or availability. The dashboard therefore reports a connection failure rather than silently presenting old humanitarian numbers as live data.

DATA CONNECTION

Public data sources

Humanitarian need: HDX Humanitarian API (HAPI) / United Nations Office for the Coordination of Humanitarian Affairs (OCHA).

Christian population: World Religion Database, as represented in data/religion.json.

Crisis context: Curated country-level data in data/crises.json, with source links retained for verification.

This dashboard presents public data and does not independently estimate humanitarian need.
