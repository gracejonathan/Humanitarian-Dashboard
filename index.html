Data definitions

How to interpret the dashboard

People in Need (PIN) is the live humanitarian figure displayed and comes directly from the HDX Humanitarian API (HAPI). The dashboard uses the national-level intersectoral total (admin level 0, population status INN) and selects the most recent reference period available for each country.

Christian population is a separate demographic measure: the percentage of a country's population identified as Christian in the World Religion Database. It is not a measure of churches, Christian organizations, humanitarian capacity, or access.

Christian presence is a separate curated country-level assessment where documented information is available. “Not yet assessed” means the dashboard has not established a sufficient country-level assessment; it does not mean absence.

Crisis began is a separate chronology field and is shown only where the dashboard has a documented start date. It does not determine the PIN figure.

Humanitarian data: OCHA / HDX HAPI. Demographic data: World Religion Database (2025 data in data/religion.json). Curated crisis chronology and Christian-presence information are maintained separately from the live PIN data.
